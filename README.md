# Cucumber BDD Testing Using Selenium 
This repository contains the code for the tutorial: <a href="https://mobisoftinfotech.com/resources/blog/cucumber-bdd-testing-with-code-example">Cucumber BDD Testing with Working Code Example – Explore the Behavior-Driven Development (BDD) Testing Framework</a> by <a href="https://mobisoftinfotech.com/">Mobisoft - App Development Company, Houston</a>

## How to Run the Project
To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mobisoftinfotech/bdd-tutorial-cucumber-integration-with-selenium-using-bdd-methodology.git

2. Open Eclipse: Launch the Eclipse IDE on your computer.

3. Select Import Option:
   Go to the menu bar and click on File.
   Select Import... from the dropdown menu.
   
4. Choose Maven Import:
   In the Import dialog, expand the Maven folder.
   Select Existing Maven Projects and click Next.
   Select Project Location:

5. Select Project Location and  locate the root directory of  your Maven project.

6. Eclipse will scan the directory for Maven projects. You should see your project listed in the "Projects" box.
   Make sure the checkbox next to your project is selected.

7. Finish the Import:
   Click the Finish button to complete the import process.
   Build the Project (if necessary):

8. After importing, you may need to build the project. Right-click on the project in the Project Explorer, go to Run As, and select 
   Maven build... to build the project.

9. Expand the imported project folder.
   Go to the path: CucumberFramework/src/test/java/com/mobisoft/common/cucumberoptions.
   Find the TestNGTestRunner file in that directory.
   Right-click on the TestNGTestRunner file.
   From the context menu, select Run As.
   Then choose TestNG Test.

**Enjoy exploring Cucumber BDD using selenium !**
